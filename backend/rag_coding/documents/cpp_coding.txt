C++ Coding Interview Implementation Guide & Patterns

1. Fast Standard I/O in C++:
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <unordered_map>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    if (!(cin >> n)) return 0;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    // Solve problem
    // cout << answer << "\n";
    return 0;
}
```

2. Standard Data Structures & Algorithms in STL:
- Dynamic Array: std::vector<int> v;
- Hash Map: std::unordered_map<int, int> countMap; (O(1) average lookup)
- Hash Set: std::unordered_set<int> seen;
- Sorted Map/Set: std::map<int, int>, std::set<int> (O(log N) Red-Black tree)
- Heap / Priority Queue: std::priority_queue<int> maxHeap; std::priority_queue<int, vector<int>, greater<int>> minHeap;
- Queue & Stack: std::queue<int>, std::stack<int>, std::deque<int>.
- Algorithms: std::sort(v.begin(), v.end()), std::binary_search, std::lower_bound, std::upper_bound, std::reverse, std::max_element.
